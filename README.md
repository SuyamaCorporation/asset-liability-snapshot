# 07 - 資産負債スナップショット

**ビルド日**: 2026-11-03
**カテゴリ**: practical
**slug**: asset-liability-snapshot

## 概要
資産と負債を項目別に入力すると純資産を自動計算し、カテゴリ別の積み上げバーチャートで家計バランスシートを一目で可視化する。

## 機能
- 資産の追加・削除（名前・金額・カテゴリ: 現金/投資/不動産/その他）
- 負債の追加・削除（名前・金額・カテゴリ: ローン/カード/その他）
- 総資産・総負債・純資産をリアルタイム計算・表示
- カテゴリ別カラーで資産内訳積み上げバー表示
- 資産 vs 負債の比率バー表示
- localStorage による全エントリの永続保存
